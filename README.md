# Physio MCQ — Anatomy & Neuroanatomy Practice

Free MCQ practice platform for Physiotherapy students preparing for MPT, AIIMS, and Railway Physiotherapy exams. 1500+ Anatomy & Neuroanatomy questions, filterable by subject, topic, and difficulty.

**Live site:** https://neetikacodes.github.io/physio-mcq/

## Files
- `index.html` — app markup (includes About / Disclaimer / Report Issue sections + SEO meta tags)
- `privacy-policy.html` — standalone Privacy Policy page (its own permanent URL, needed for AdSense)
- `style.css` — all styling
- `app.js` — quiz logic
- `data.js` — question bank
- `robots.txt`, `sitemap.xml` — SEO

## Deploy on GitHub Pages
1. Push all these files to the root of your `physio-mcq` repo.
2. In repo Settings → Pages, set source to the `main` branch, root folder.
3. Site will be live at `https://<username>.github.io/physio-mcq/`.

> Note: the "Report Issue" button opens a pre-filled GitHub Issue for `Neetikacodes/physio-mcq` — update the `GITHUB_REPO` value inside `index.html` if your repo name/owner is different.
